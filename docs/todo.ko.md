## MCU 모션 스케줄러의 실행시간 — 2026-11-14 등록

상태: 보류. 연산 시간 확인과 개선 후보를 기록한 것이며, MCU 시간 측정·실물 테스트·업로드는 수행하지 않았다.
PC 오프라인 시뮬레이션에서는 후보 시도 횟수를 기록했으나 MCU 실행시간은 측정하지 않았다.

현재 `advance_drive()`는 중간 출력 후보를 최대 12회 평가한다. 최종 목표 계산까지 포함하면
모션 갱신당 역기구학이 최대 13회 실행될 수 있다. 반복 횟수 상한은 실행시간 예산 충족을
입증하지 않으며, CAN 처리와 공유하는 메인 루프에 대한 영향도 아직 확인되지 않았다.

- [ ] CAN 송수신·오류 처리·인터럽트 여유를 고려해 모션 갱신 주기와 실행시간 예산을 정한다.
- [ ] `motion`, `loop_period`, `rx_poll_gap_us` 및 CAN 송신 지연·응답 누락을 함께 확인할
  계측 조건을 정한다. 실제 계측은 별도 작업으로 진행하며, 관측 최대값과 보장된 최악 실행시간을 구분한다.
- [ ] 메인 루프마다 수행하는 목표 역기구학 계산을 줄일 수 있는지 검토한다.
  고정 주기 갱신, `dt=0` 중복 계산 제거, 입력·설정 변경을 반영하는 목표 캐시를 후보로 둔다.
- [ ] 시간 예산이 부족하면 보수적인 변화율 경계와 적은 고정 횟수의 후보 검사로 대체하는 방식을 검토한다.
  현재 지점의 미분값만으로 비선형 구간 전체가 제한을 만족한다고 가정하지 않는다.
- [ ] 개선 시 같은 운동 상태에서 조향·RPM을 생성하는 조건과 각 출력의 변화율 제한을 유지한다.
  평균 부하 감소와 단일 호출 최대 지연 감소를 구분해 결과를 기록한다.
